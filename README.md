## Quick Setup
1. Open `index.html` in your browser to preview locally.
2. Customize firm name, monogram (`AV`), cities, and copy inside `index.html`.
3. Adjust palette variables in `style.css` (`:root`).
4. Replace images in `assets/`:
   - `assets/hero-luxury-boardroom.jpg`
   - `assets/advisory-study.jpg`

---

## Form Integration
Update `<form id="luxForm" action="#" ...>` in `index.html` with your Formspree, Basin, or Netlify Forms endpoint to receive live private inquiries.
